# Фронтенд «Грибница»

## Запуск готового интерфейса

Из корня репозитория в Python-окружении с установленным `requirements.txt`:

```powershell
python -m mycelium.serve
```

Открыть http://localhost:8000. Node.js и интернет для готовой сборки не нужны.

## Разработка и обновление сборки

```powershell
cd frontend
npm ci
npm run dev
```

Dev-сервер обращается к backend на http://localhost:8000. При необходимости задайте `NEXT_PUBLIC_API_BASE`. В production адрес API относительный: `/api/...`.

`npm run build` синхронизирует сохранённые результаты из `out/web/`, экспортирует статический Next.js и публикует их в `web/dist/`. Коммитить исходники `frontend/` и весь `web/dist/`. `.env`, `.venv`, `node_modules` и `.next` не коммитить.

Без сервера интерфейс явно показывает режим сохранённых данных. Новые блокировки и живые вопросы в этом режиме недоступны. `NEXT_PUBLIC_DATA_MODE=snapshot` принудительно включает сохранённые данные.

Обзор путей сохраняет презентационную композицию. Режимы «Топ-30 + соседи», «Весь граф» и окрестность найденного GID используют координаты backend. Анимация входящих путей не обозначает количество отключённых курьеров; влияние блокировки берётся из POST `/api/block`.
