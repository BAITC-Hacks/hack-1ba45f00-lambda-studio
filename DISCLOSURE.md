# Раскрытие: что стороннее в «Грибнице»

## Данные и стартовый код организаторов

| Что | Где | Как использовано |
|---|---|---|
| Датасет кейса «Граф денег» (edges / nodes / transactions.parquet + README) | `data/` | без изменений; единственный источник данных, внешние данные не подключаются |
| Стартовый код организаторов (`starter.py`, README, requirements) | `starter/` | без изменений. На его основе написан `mycelium/load.py`: загрузка parquet, проверка «транзакции складываются в рёбра», сборка направленного графа. Базовые метрики (степени, суммы, доля пропуска, флаг 4-го колена) развиты в `mycelium/features.py` |

## Библиотеки Python (`requirements.txt`)

| Библиотека | Лицензия | Для чего |
|---|---|---|
| pandas | BSD-3-Clause | таблицы узлов и рёбер, выгрузка CSV |
| pyarrow | Apache-2.0 | чтение parquet |
| numpy | BSD-3-Clause | вычисления, силовая раскладка схемы |
| networkx | BSD-3-Clause | граф, betweenness, сильно связные компоненты, Louvain (`community.louvain_communities`) |
| fastapi | MIT | API для экрана |
| uvicorn | BSD-3-Clause | HTTP-сервер |
| openai | Apache-2.0 | клиент OpenAI API для необязательного ИИ-аналитика |

| pytest, httpx | MIT, BSD-3-Clause | тесты API |

Алгоритмы: Louvain (Blondel et al., 2008) — реализация networkx; раскладка схемы — алгоритм
Фрюхтермана — Рейнгольда (1991), своя реализация на numpy в `mycelium/layout.py`.

## Модель ИИ

| Что | Подробности |
|---|---|
| Сервис | OpenAI API (chat completions с function calling), **необязательный** |
| Модель | задаётся в `.env` (`OPENAI_MODEL`); по умолчанию в `.env.example` — `gpt-4.1-mini` |
| Что получает модель | только результаты наших инструментов над посчитанными выходами (`mycelium/ai/tools.py`) или `out/facts.json`: обезличенные gid, роли, метрики. Сырых данных, ФИО и ИИН нет |
| Что делает модель | пересказывает посчитанные факты простым языком. Роли и цифры считает код, ответ модели сверяется с графом (`mycelium/ai/verify.py`) |
| Сохранённая справка `out/brief.md` | источник указан в `out/brief_check.json` (`source`): `template` — собрана кодом из `facts.json` без модели, `openai` — сгенерирована моделью |

Без ключа ИИ-аналитик выключен, всё остальное работает.
