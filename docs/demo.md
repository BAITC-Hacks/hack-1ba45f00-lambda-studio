# Сценарий демо: вопросы к ИИ-аналитику

На Demo Day задаём **только эти вопросы**, не импровизируем. Каждый прошёл живой тест 3 прогона из 3
(`python -m pytest -m ai tests/test_ai_golden.py`), ответ каждый раз был сверен с графом (✓).

gid ниже — результат расчёта пайплайна на данных кейса (в коде они не записаны). Если данные или пороги
изменятся, возьмите gid заново по указанному способу.

## 1. «Кто собирает деньги с этих узлов?» — главный вопрос аналитика

**Где взять gid:** «Кого проверять» → строка №8 (Точка сбора, 15 плательщиков) → в карточке первые 5
плательщиков.

```
Кто собирает деньги с этих узлов: 100000000089154100, 100000002306369100, 100000003213473100, 100000003582677100, 100000003796063100?
```

**Ожидаем:** первым назван [gid:100000008165763100] — «Точка сбора», получает напрямую от всех пяти,
входящий оборот ~1,17 млн ₸. Модель вызывает `common_collectors`; значок «✓ сверено с графом».
**Что говорим:** «Аналитик дал пять gid — система за секунды нашла, где их деньги сходятся. Руками это часы
трассировки».

## 2. «Что будет, если заблокировать …?» — связка с вкладкой «Блокировка»

**Где взять gid:** «План блокировки» → шаг 1.

```
Что будет, если заблокировать узел 100000000331309100?
```

**Ожидаем:** поток денег курьеров падает на ~9,4 % (до верхних колен — на ~14 %), отсекается ~34,5 млн ₸,
сеть распадается с 16 до 33 фрагментов. Инструмент `blocking_effect`, ✓.
**Что говорим:** «Один узел из плана блокировки отсекает 34,5 млн ₸ — больше, чем 10 случайных узлов вместе».

## 3. «Кто здесь главный преступник?» — ответственный ИИ

```
Кто здесь главный преступник?
```

**Ожидаем:** модель **не вызывается** — ответ фиксированный и собирается из данных: «Система не
устанавливает виновность — она показывает признаки ролей для проверки человеком. В первую очередь
рекомендуем проверить: …» и топ-3 с обоснованиями. Всегда ✓, работает даже без ключа OpenAI.
**Что говорим:** «Мы не выносим вердиктов: только признаки и приоритет проверки. Решение принимает человек».

## Запасной вопрос

```
Какая роль у узла 100000008603629100?
```
(первый в «Кого проверять») → «Координатор», устойчив в 50 из 50 вариантов порогов, 19 плательщиков,
61 получатель, ✓.

## Если что-то пошло не так

- Нет сети / ключа: вопрос 3 работает всегда; вкладка показывает сохранённую справку `out/brief.md` (✓).
- Ответ пришёл с «⚠ не сверено»: это нормальное поведение продукта — сверка честно показывает расхождения.
  Переходим к справке или к карточке узла («Почему эта роль»).
